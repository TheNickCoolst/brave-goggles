# Brave Goggles

Custom Goggles for Brave Search.

## ai-focus.goggle
Re-ranks Brave Search toward primary AI/ML sources - research papers, frontier labs, model hubs, agent frameworks and quality news. Buries SEO spam and listicles.

**Import in Brave:** https://search.brave.com/goggles -> Add Goggle -> paste the raw URL of `ai-focus.goggle`.
